# MORE Workspace

A web-based data management and analytics system.

## Tech Stack

- **Core**: React 19, TypeScript
- **Bundler**: Vite
- **Styling**: TailwindCSS
- **Storage**: Cloud Firestore

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Development Server

```bash
npm run dev
```

### 3. Build for Production

```bash
npm run build
```

### 4. Lint & Typecheck

```bash
npm run typecheck
```
